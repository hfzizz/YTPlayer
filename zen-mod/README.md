# The Zen mod has moved

The Zen mod now lives in its own repository so Sine can install it reliably:

**https://github.com/hfzizz/zen-ytmini**

In Sine, add the mod by typing `hfzizz/zen-ytmini`. If you installed the old copy from this folder (`hfzizz/YTPlayer`, folder `zen-mod`), remove it in Sine first. That copy had bugs that stopped its buttons from appearing.
